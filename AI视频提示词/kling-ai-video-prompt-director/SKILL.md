# 可灵 Kling AI 视频提示词导演 Skill

## 0. 使用目标

当用户需要为可灵 Kling AI 生成、分析或优化视频提示词时，使用本 Skill。

本 Skill 的目标不是堆关键词，而是把用户的想法转换成一份可执行的导演式视频提示词。输出应帮助模型理解：谁在画面里、发生了什么、镜头怎么拍、光线和氛围是什么、动作如何连续、哪些内容必须保持不变、哪些内容禁止出现。

适用场景包括：

1. 文生视频 Text-to-Video
2. 图生视频 Image-to-Video
3. 首尾帧 Start and End Frames
4. 多镜头 Multi-Shot
5. 自定义多镜头 Custom Multi-Shot
6. Kling 3.0 视频生成
7. Kling 3.0 Omni 多模态生成
8. Kling O1 多模态生成与视频编辑
9. Elements 角色、产品、场景一致性
10. Motion Control 动作参考控制
11. 故事板转视频
12. 分镜脚本转视频提示词
13. 短剧、广告、产品种草、房产看房、电影感情绪片

## 1. 总体输出原则

### 1.1 像导演，不像关键词列表

不要只输出零散词语，例如：

```text
女孩，街道，伤心，电影感，高清。
```

应输出带有动作、镜头、场景、情绪推进的导演式描述，例如：

```text
一位年轻女性站在清晨地铁口，手里握着一朵略微枯萎的蓝色小花。她先低头看花，停顿片刻，随后缓慢抬眼看向远处，表情克制、疲惫，像是忍住没有哭。镜头从手中蓝色小花近景缓慢前推到人物脸部特写，背景通勤人群轻微虚化，冷白色晨光，低饱和真实摄影质感。
```

### 1.2 一个镜头只承载一个核心动作

5 秒或 10 秒视频里不要塞太多动作。优先使用：

```text
低头 → 抬眼
伸手 → 停住
转身 → 回望
握紧 → 松开
靠近 → 停顿
微笑 → 表情消失
```

避免：

```text
跑进房间，坐下，哭泣，打电话，争吵，摔门离开，回忆过去。
```

### 1.3 用动作表达情绪

不要只写“她很难过”。应写出可被画面执行的动作：

```text
她低头看着手中的蓝色小花，手指轻轻收紧，停顿后缓慢抬眼，眼神湿润但没有哭出来。
```

### 1.4 图生视频不要重写参考图

如果用户已经提供参考图，提示词重点是“让图里的人或物怎么动”，不要大段重新描述图片内容。重复描述可能导致换脸、换衣服、改场景。

推荐写法：

```text
使用参考图作为首帧，保持人物外貌、服装、发型、身体比例、场景结构、光线和色彩不变。女主站在原地，先低头看向桌上的饭菜，随后轻轻吸气，抬眼看向门口，表情从平静变成强忍难过。镜头缓慢前推，背景保持稳定。
```

## 2. 文生视频 Text-to-Video

### 2.1 核心公式

文生视频适合从空白画面生成内容。提示词应包含：

```text
主体 + 主体描述 + 主体运动 + 场景 + 镜头语言 + 光线 + 氛围 + 负面限制
```

也可以按下面结构写：

```text
【主体是谁】
【主体长什么样 / 什么状态】
【主体正在做什么】
【场景在哪里】
【镜头怎么运动】
【光线、色彩、氛围】
【画面风格】
【负面限制】
```

### 2.2 字段解释

#### 主体 Subject

主体是画面中最重要的对象，可以是人物、动物、产品、建筑、车辆、植物、机器人等。

示例：

```text
一位年轻女性
一只成年拟人猫
一个纯钛保温杯
一栋未来感公寓
一辆宫廷自行车
```

#### 主体描述 Subject Description

人物可描述：年龄感、发型、服装、身材、表情、姿态、气质。

产品可描述：材质、颜色、造型、大小、表面纹理、反光、使用状态。

场景可描述：空间结构、时间、天气、道具、背景层次、前景元素。

示例：

```text
一位清秀的成年东方女性，长黑微卷发，穿浅色风衣，神情克制疲惫，手里握着一朵略微枯萎的蓝色小花。
```

#### 主体运动 Subject Movement

主体运动要短、明确、连续，最好包含开始状态、中间变化、结束状态。

示例：

```text
女孩站在门口停顿两秒，低头看向手中的蓝色小花，随后缓慢抬眼，像是终于下定决心离开。
```

#### 场景 Scene

不要只写“街道”或“房间”，要补足空间信息。

示例：

```text
清晨的地铁口，人群从背景匆匆经过，路面略湿，冷白色晨光从画面左侧照来。
```

```text
狭窄出租屋门口，半开的房门透出暖光，门外楼道是冷色荧光灯，门边放着一个黑色小行李箱。
```

#### 镜头语言 Camera Language

常用镜头词：

```text
固定镜头
缓慢前推
轻微后拉
横向跟拍
手持轻晃
低角度仰拍
俯拍
特写
中景
远景
长焦压缩
浅景深
焦点从前景转移到人物脸上
```

示例：

```text
镜头缓慢前推，焦点从她手里的蓝色小花转移到她的眼睛。
```

```text
低角度中景跟拍，人物从画面右侧进入，背景人群轻微虚化。
```

#### 光线 Lighting

常用光线词：

```text
清晨冷光
黄昏逆光
窗边自然光
室内暖光
冷白荧光灯
低照度夜景
柔和漫反射
边缘轮廓光
高反差光影
```

示例：

```text
冷白色清晨自然光，低饱和色彩，人物脸部有柔和侧光，背景轻微虚化。
```

#### 氛围 Atmosphere

常用氛围词：

```text
安静
压抑
克制
孤独
荒诞
喜剧感
高级
冷淡
温暖
紧张
梦境感
纪录片感
广告感
电影感
```

示例：

```text
整体氛围安静克制，像一段真实纪录片片段，不夸张，不煽情。
```

### 2.3 文生视频通用模板

```text
一段真实电影感视频。

主体：
[写清楚主体是谁、年龄感、外貌、服装、状态]

动作：
[写清楚主体在视频中的连续动作，控制在一个核心动作内]

场景：
[写清楚时间、地点、空间结构、背景元素]

镜头：
[景别 + 运镜 + 焦点变化]

光线与氛围：
[光线、色彩、情绪、风格]

画面要求：
真实摄影感，动作自然，人体比例准确，细节清晰，低饱和电影色彩。

负面限制：
不要字幕，不要水印，不要 logo，不要卡通感，不要畸形手指，不要夸张表情，不要多余人物。
```

### 2.4 电影感短片模板

```text
一段低饱和电影感真实摄影视频。

一位年轻女性站在清晨地铁口，长黑微卷发，穿浅色风衣，手里握着一朵略微枯萎的蓝色小花。她先低头看花，停顿片刻，随后缓慢抬眼看向远处，表情克制、疲惫、像是忍住没有哭。

场景是清晨城市地铁口，路面略湿，背景有通勤人群经过但轻微虚化。镜头从手中蓝色小花的近景缓慢前推到人物脸部特写，浅景深，冷白色晨光，安静压抑的氛围。

真实摄影感，纪录片质感，动作自然，人物比例准确，面部清晰。

不要字幕，不要文字，不要水印，不要过度表演，不要卡通感，不要畸形手指。
```

### 2.5 产品广告模板

```text
一段高级产品广告风格视频。

主体是一个纯钛保温杯，杯身为独特结晶色彩，表面有细腻金属光泽，杯型小巧精致。杯子放在干净的浅色桌面上，旁边有水滴、柔和晨光和少量生活化道具。

镜头从杯身局部纹理特写开始，缓慢环绕半圈，随后轻轻前推到杯口和杯身结晶色彩。背景保持简洁，浅景深，光线柔和，突出纯钛材质的干净、轻盈和高级感。

真实摄影质感，商业广告级布光，画面干净，产品边缘清晰，金属反光自然。

不要文字，不要 logo，不要多余品牌，不要塑料质感，不要夸张彩虹光，不要畸形杯身。
```

## 3. 图生视频 Image-to-Video

### 3.1 核心公式

图生视频的核心不是重写画面，而是控制图里的对象怎么动。

推荐公式：

```text
主体 + 运动
```

或者：

```text
主体动作 + 背景动作
```

更完整的实操结构：

```text
保持参考图主体一致。
主体做什么动作。
镜头如何运动。
背景是否运动。
情绪如何变化。
哪些东西不能改变。
```

### 3.2 图生视频关键原则

#### 原则 1：不要重复大段描述参考图

错误写法：

```text
一个女孩，黑色头发，白色衣服，站在房间里，房间有桌子，桌子上有饭菜，女孩很难过。
```

更好的写法：

```text
保持参考图中的人物外貌、服装、场景和光线不变。女主站在原地，先低头看向桌上的饭菜，随后轻轻吸气，抬眼看向门口，表情从平静变成强忍难过。镜头缓慢前推，背景保持稳定。
```

#### 原则 2：动作要短、清楚、连续

推荐：

```text
低头 → 抬眼
转身 → 停住
伸手 → 缩回
微笑 → 表情消失
握紧 → 松开
看远处 → 回头
```

不推荐：

```text
跑步、摔倒、爬起来、吵架、哭泣、离开、回忆。
```

#### 原则 3：明确保持不变的内容

图生视频必须强调：

```text
保持人物脸部一致
保持服装一致
保持场景结构不变
保持主体比例真实
保持镜头连续
```

### 3.3 图生视频通用模板

```text
使用参考图作为首帧，保持参考图中的人物身份、脸部特征、服装、发型、身体比例、场景结构、光线和色彩不变。

动作：
[主体在几秒内做什么动作，动作要连续、自然、不要过多]

表情：
[表情从什么状态变化到什么状态]

镜头：
[固定 / 前推 / 后拉 / 跟拍 / 轻微手持]

背景：
[背景是否保持静止，是否有轻微风、光影、人群、窗帘等运动]

画面要求：
真实摄影感，动作自然，面部稳定，服装不变形，人体比例准确。

负面限制：
不要换脸，不要换衣服，不要改变场景，不要新增字幕，不要水印，不要畸形手指，不要人物缩小成儿童比例。
```

### 3.4 角色图生视频模板

```text
使用参考图作为首帧，严格保持人物外貌、发型、服装、头饰、身体比例和场景不变。

女主站在原地，先维持端庄克制的表情，随后眼神快速看向画面右侧，眉头轻微收紧，嘴唇微微抿住，表现出焦急但仍强忍失态的情绪。衣袖和头饰流苏随着身体轻微动作自然晃动。

镜头为中近景固定镜头，轻微前推，背景保持稳定，光线不变。

真实摄影感，动作自然，面部清晰，人物比例真实。

不要换脸，不要变小，不要变成儿童，不要夸张表情，不要卡通感，不要字幕，不要水印。
```

### 3.5 道具图生视频模板

```text
使用参考图作为首帧，保持产品造型、颜色、材质、比例和背景不变。

杯子保持在画面中心，镜头缓慢前推并轻微环绕，杯身金属结晶纹理随着光线变化产生细腻反光。背景保持简洁，只有轻微自然光变化。

真实摄影质感，产品边缘清晰，金属质感准确，画面干净高级。

不要改变杯型，不要增加文字，不要增加 logo，不要变成塑料材质，不要夸张反光，不要背景杂乱。
```

## 4. 首尾帧 Start and End Frames

### 4.1 使用场景

首尾帧适合控制“从 A 状态变到 B 状态”。

适合：

1. 人物转身
2. 表情变化
3. 产品开合
4. 光线变化
5. 场景从白天变黄昏
6. 人物从站立变坐下
7. 房间从整洁变凌乱
8. 花从新鲜变枯萎

### 4.2 核心写法

```text
从首帧自然过渡到尾帧。
保持人物身份、服装、场景结构和画面风格一致。
中间动作要连续、自然、不要跳变。
```

### 4.3 首尾帧模板

```text
使用第一张图作为首帧，第二张图作为尾帧。保持人物身份、脸部特征、服装、身体比例、场景结构、光线风格一致。

视频表现人物从首帧状态自然过渡到尾帧状态。动作过程要连贯，人物先轻微停顿，然后缓慢完成动作，表情从[首帧情绪]逐渐变化为[尾帧情绪]。

镜头保持稳定，轻微前推，背景不发生明显变化。

真实摄影感，动作自然，过渡平滑，人物比例准确，面部稳定。

不要换脸，不要换衣服，不要改变场景，不要突然跳切，不要新增字幕，不要水印，不要畸形手指。
```

## 5. 多镜头 Multi-Shot

### 5.1 使用场景

Multi-Shot 适合：

1. 一个视频里需要多个景别
2. 一段剧情有起承转合
3. 需要从远景到特写
4. 需要人物对白
5. 需要转场
6. 需要短剧节奏
7. 需要 15 秒内讲完整一段小故事

### 5.2 基础写法

```text
生成一段多镜头电影感视频。
镜头 1：建立场景。
镜头 2：推进动作。
镜头 3：情绪特写。
镜头之间自然衔接，人物和场景保持一致。
```

### 5.3 Custom Multi-Shot 标准格式

```text
Shot 1，3s：
[景别 + 场景 + 人物动作 + 镜头运动]

Shot 2，4s：
[景别 + 动作推进 + 情绪变化 + 镜头运动]

Shot 3，5s：
[特写 / 关键动作 / 情绪落点]

整体要求：
保持同一人物、同一服装、同一场景逻辑。镜头之间自然衔接，光线和色彩统一。
```

### 5.4 15 秒短剧模板

```text
生成一段 15 秒多镜头真实电影感短剧。

Shot 1，4s：
远景，清晨宫道极长，女主骑着宫廷自行车从远处快速驶来，两个宫女在后方小跑追赶。镜头长焦固定，压缩宫道距离，晨雾轻微流动。

Shot 2，5s：
中景跟拍，车轮轻微卡在宫门门槛，女主身体前倾但稳住没有摔倒，旗头和流苏晃动。她表情焦急。镜头轻微手持跟随。

Shot 3，6s：
近景特写，女主抬眼看向宫门内，眉头微收，嘴唇抿住，呼吸急促，表现出“快迟到了但不能失态”的焦急。晨光照在脸侧，背景宫门虚化。

整体要求：
人物脸部、服装、头饰、身体比例保持一致。动作自然连续，具有喜剧感。真实摄影感，电影质感，低饱和清晨光。

负面限制：
不要字幕，不要文字，不要水印，不要换脸，不要变成儿童比例，不要卡通感。
```

## 6. Kling 3.0 Omni

### 6.1 使用目标

Omni 更适合多模态导演式创作，可以结合：

1. 文本提示词
2. 参考图
3. 参考视频
4. Elements 角色资产
5. 声音
6. 多镜头
7. 人物对白
8. 多角色互动
9. 场景引用
10. 道具引用

### 6.2 核心写法

如果有多个参考元素，必须把每个元素的作用写清楚。

推荐格式：

```text
@角色A 做什么
@角色B 做什么
@场景 作为背景
@道具 被谁使用
Shot 1...
Shot 2...
Shot 3...
```

错误写法：

```text
让他们在房间里聊天。
```

更好的写法：

```text
@女主 坐在 @出租屋 场景里的窄餐桌旁，低头看着桌上的饭菜。@男主 只出现手部，坐在画面前景右侧。两人之间保持沉默，气氛压抑。
```

### 6.3 Omni 多角色对白模板

```text
使用 @女主 和 @男主 作为固定角色。保持两人的脸部、服装、发型、身体比例和声音一致。使用 @客厅 作为背景场景。

Shot 1，4s：
中景，@女主 坐在沙发左侧，低头看手机，@男主 从画面右侧进入。室内暖光，夜晚安静氛围。

Shot 2，5s：
过肩镜头，@男主 看向 @女主，轻声说：“你今天怎么这么晚？” @女主 没有立刻回答，只是把手机屏幕按灭。

Shot 3，5s：
近景特写，@女主 抬眼看向 @男主，声音很轻地说：“我只是有点累。” 她表情克制，没有哭。

整体要求：
对白口型自然，声音和角色匹配。镜头之间自然衔接，人物一致，场景一致，光线一致。

负面限制：
不要角色串音，不要错位口型，不要字幕，不要新增人物，不要换脸，不要夸张表情。
```

## 7. Elements 角色、产品、场景一致性

### 7.1 使用目标

Elements 适合解决人物、宠物、产品、场景在多个视频里不一致的问题。

适合建立 Elements 的对象：

1. 主角
2. 配角
3. 宠物
4. 产品
5. 特定道具
6. 固定场景
7. 服装造型
8. 品牌视觉元素

### 7.2 使用原则

1. 一个 Element 对应一个明确主体
2. 不要把多个主体塞进同一个 Element
3. 人物最好提供正面、侧面、半身、全身、表情变化
4. 产品最好提供正面、侧面、细节、使用场景
5. 场景最好提供主视角、反打角度、局部细节
6. 提示词里用 @ 明确调用 Element
7. 不要只写“保持一致”，要写“谁保持一致”

### 7.3 Elements 提示词模板

```text
使用 @女主 作为固定人物元素，保持她的脸部特征、发型、服装、年龄感、身体比例和气质一致。
使用 @自行车 作为固定道具元素，保持造型、比例、颜色和材质一致。
使用 @宫道 作为背景场景元素，保持空间结构、光线方向和时代氛围一致。

@女主 骑着 @自行车 穿过 @宫道，动作自然，车身轻微摇晃，衣袖和流苏随动作摆动。镜头中景跟拍，背景轻微运动模糊。
```

## 8. Kling O1 多模态生成与编辑

### 8.1 使用目标

O1 更适合“输入很多东西，然后让模型理解创作意图”。

O1 可用于：

1. 参考图生成视频
2. 多元素组合
3. 首尾帧过渡
4. 视频续写
5. 局部修改
6. 风格转换
7. 替换人物服装
8. 删除画面元素
9. 改变天气、时间、光线
10. 多模态创作

### 8.2 多元素组合公式

```text
元素详细描述 + 元素之间的互动 + 环境背景 + 光线 / 风格 / 镜头
```

### 8.3 O1 多元素模板

```text
使用参考图中的人物作为主角，保持人物脸部、发型、服装、身体比例和气质一致。
使用参考图中的道具作为关键物件，保持造型、材质和比例一致。
使用参考图中的场景作为背景，保持空间结构和光线方向一致。

人物与道具产生明确互动：[写具体互动动作]。
镜头：[写景别和运镜]。
情绪：[写人物表情变化]。
风格：[真实摄影 / 电影感 / 广告感 / 纪录片感]。

不要改变人物身份，不要改变服装，不要改变道具比例，不要新增无关元素，不要字幕，不要水印。
```

### 8.4 O1 局部修改模板

```text
保持原视频的人物、构图、镜头运动、光线和场景不变。
只修改：[需要修改的对象或区域]。

把 [原对象] 改为 [新对象]，要求材质、透视、光影和画面风格自然融合。
其他区域不要变化。

不要改变人物脸部，不要改变衣服，不要改变镜头，不要改变背景结构，不要新增字幕，不要水印。
```

## 9. Motion Control 动作控制

### 9.1 使用目标

Motion Control 适合让一个角色模仿参考视频里的动作。

适合：

1. 舞蹈动作
2. 武打动作
3. 走路姿态
4. 回头动作
5. 手势动作
6. 表演动作
7. 运动姿态
8. 特定人物肢体语言

### 9.2 使用原则

1. 上传动作参考视频
2. 上传角色图
3. 尽量使用方向一致的角色图
4. 如果要保持脸部，需要绑定面部 Element
5. 角色图最好清晰，脸部不要遮挡
6. 提示词里只强调动作执行和风格，不要过度改造角色

### 9.3 Motion Control 模板

```text
使用参考动作视频作为动作轨迹，使用角色参考图作为人物外观。
保持角色脸部、发型、服装、身体比例和气质一致。
角色按照参考动作完成相同的身体运动，动作节奏自然，重心稳定，肢体比例准确。

场景为 [写场景]。
镜头为 [写景别和运镜]。
光线为 [写光线]。
整体风格为真实摄影感。

不要换脸，不要改变服装，不要动作断裂，不要肢体畸形，不要多余人物，不要字幕，不要水印。
```

## 11. 常见问题与修正方法

### 11.1 动作太多

错误：

```text
女孩跑进房间，坐下，哭，打电话，摔门离开。
```

优化：

```text
女孩站在门口停顿，低头看向手里的手机，随后缓慢抬眼，表情从犹豫变成失落。
```

### 11.2 图生视频重复描述参考图

错误：

```text
一个穿绿色衣服的女人，头戴旗头，站在宫殿里……
```

优化：

```text
保持参考图中的人物外貌、服装、头饰和场景不变。女主轻轻转头看向宫门方向，表情从平静变成焦急。
```

### 11.3 只写情绪，不写动作

错误：

```text
她很伤心。
```

优化：

```text
她低头看着手里的蓝色小花，手指轻轻收紧，停顿后缓慢抬眼，眼神湿润但没有哭出来。
```

### 11.4 镜头语言缺失

错误：

```text
杯子很好看。
```

优化：

```text
镜头从杯身结晶纹理特写开始，缓慢环绕半圈，柔和晨光在金属表面形成细腻反光。
```

### 11.5 场景逻辑不清

错误：

```text
人在房子里走。
```

优化：

```text
人物从入户门进入，经过玄关走向客厅阳台，正门与阳台形成一条清晰的公共轴线，镜头从背后稳定跟拍。
```

## 12. 推荐短视频工作流

### 12.1 先写剧情目标

在生成前先明确：

```text
这个视频要表达什么？
是搞笑、情绪、种草、解释、恐怖、反转，还是广告？
```

### 12.2 再拆镜头

15 秒结构：

```text
0-4 秒：建立场景和人物处境
4-10 秒：动作升级或冲突出现
10-15 秒：情绪落点或反转
```

30 秒结构：

```text
分镜 1：10 秒，开场抓人
分镜 2：10 秒，冲突升级
分镜 3：10 秒，反转 / 落点 / 产品出现
```

### 12.3 每个镜头只写一个核心动作

例如：

```text
镜头 1：骑车冲来
镜头 2：车轮卡住
镜头 3：女主焦急特写
```

不要写：

```text
骑车、摔倒、聊天、回忆、哭、跑走。
```

### 12.4 先控制画面，再控制情绪

推荐顺序：

```text
人物一致性 → 场景一致性 → 动作自然 → 镜头运动 → 表情变化 → 光线氛围 → 负面限制
```

## 18. 核心结论

可灵提示词的关键不是堆形容词，而是像导演一样控制：

1. 主体
2. 动作
3. 场景
4. 镜头
5. 光线
6. 情绪
7. 连续性
8. 负面限制

文生视频重点写完整画面。
图生视频重点写动作，不要重写参考图。
多镜头重点写每个 Shot 的时长、景别、动作和衔接。
Omni 和 O1 重点写清楚每个参考元素的身份、作用和互动关系。
Elements 重点解决角色、产品、场景的一致性。
Motion Control 重点解决动作模仿和身体运动一致性。

真正好用的可灵提示词应该像一份简短但精准的导演分镜，而不是关键词清单。
