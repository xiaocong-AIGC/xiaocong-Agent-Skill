# 即梦 Seedance 2.0 — 全能参考模式用法（故事板外的替代流程）

> 来源：即梦官方使用手册（jimeng-seedance-prompter）。
> 定位：**当"故事板→视频"生成不稳定时（空间漂移/编出未建空间/乱开场/高难反转），改用这套"资产/参考驱动"流程**。
> 与本 Skill 的关系：故事板降为导演规划；生成以 `@素材` 参考 + 提示词驱动。配合 [[reference-no-redescribe]]（引用资产不重复描述）、[[spatial-description-enough]]、[[seedance-dialogue-format]]。

## 输入与限制
- 图片 ≤9（jpeg/png/webp/bmp/tiff/gif，每张<30MB）；视频 ≤3（总 2–15s）；音频 ≤3（总 ≤15s）；**总文件 ≤12**。
- 生成时长 4–15s 可选。
- ⚠️ 不上传可辨识的真人脸素材（会被拦/有风险）。

## `@素材` 交互语法（每个素材必须标明用途）
- `@图1 作为首帧` / `@图2 作为尾帧`
- `参考 @图1 的人物形象` / `@图3 提供角色造型`
- `场景参考 @图X`
- `参考 @视频1 的运镜` / `参考 @视频2 的动作`
- `@音频1 用于配乐`
> 多素材要**逐一标注用途**，不要含糊"参考@视频1做一样的"。

## 常用结构
- **首帧+文本**：`@图1 作为首帧，[后续动作]，[运镜]，[情绪/氛围]`
- **首帧+尾帧**（锁住变化/高难反转最稳）：`@图1 作为首帧，@图2 作为尾帧，[中间如何演变]`
- **角色一致性**：`参考@图1的角色形象，[场景]，[动作]，[运镜]`
- **一镜到底**：`一镜到底，从[起]…[运镜]…到[止]`
- **时间轴分镜（>8s 推荐）**：`0–N秒：[画面]` / `N–M秒：[画面]` …（对白短剧可在对应时段写台词）

## 术语（与本 Skill 镜头语言一致）
- 运镜：推/拉/摇/移/环绕/跟拍/升降/希区柯克变焦。
- 景别：特写/近景/中景/全景/远景/大远景。
- 转场：切镜/溶解/淡入淡出/匹配剪辑/遮挡转场。

## 最佳实践
1. 提示词具体（谁/在哪/穿什么/干什么/什么光）。
2. 参考关系明确（参考@X 的"运镜/动作/造型"，分别说清）。
3. 时间轴/分镜精确到段。
4. 运镜写清：机位高度 + 移动方式 + 速度。
5. 多素材逐一标注用途。
6. 引用已有资产时**不重复描述它已锁的内容**（见 [[reference-no-redescribe]]）。

## 在本项目里的落法
- 资产来源：从场景识别板出**场景图 plate** 当 `@场景`；角色用 `@char_*`；难控开场/反转用 **首帧/尾帧 keyframe**；道具用 `@fx_*`。
- 没有资产的空间（楼道/室外）一律不露出。
- 台词：在对应镜头/时段写中文原话 + 谁说 + 语气（旁白 V.O.），留够时长。
