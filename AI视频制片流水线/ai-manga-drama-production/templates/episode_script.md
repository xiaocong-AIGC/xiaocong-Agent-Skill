# Template — Episode Script (AI Manga Drama)

> 用途：把单集大纲写成**适合 AI 漫剧生产**的脚本（不是传统小说）。
> 剧本分析/说明用中文；台词与画面描述可中英按项目需要，但要利于后续转镜头。
> **不要写死内容**；下列为结构字段，内容由 AI 按项目自创。

## EPISODE SCRIPT

- **EPISODE TITLE**：本集标题
- **ESTIMATED DURATION**：预计时长（默认 60–120s；注明）
- **LOGLINE**：一句话本集内容
- **OPENING HOOK (first 5s)**：前 5 秒钩子怎么呈现

### SCENES（按场景重复以下结构）

#### SCENE 0X — <场景名 / 地点 / 时间>
- **SCENE**：地点、时间、氛围一句话
- **CHARACTERS**：本场出场角色（与角色资产命名一致）
- **VISUAL ACTION**：可被拍出来的具体动作与画面（避免只写心理）
- **DIALOGUE**：台词（精炼、口语、短）
- **NARRATION**：旁白/字卡（如有）
- **SOUND**：环境音/音效/静默提示
- **EMOTIONAL BEAT**：本场情绪节拍（valence/arousal 走向）
- **CAMERA INTENT（可选）**：景别/运镜意图，便于后续分镜
- **CONTINUITY NOTE（可选）**：与前后场景的连续性提示

### ENDING
- **EMOTIONAL PEAK / TWIST**：本集情绪高点或反转
- **ENDING HOOK**：结尾钩子（留给下一集的悬念）

### 生产化提示（写在脚本末尾，便于进入 MODULE B）
- 本集预计需要的 **角色资产 / 场景资产 / 道具资产** 清单（命名建议）。
- 本集预计 **sequence 拆分** 提示：哪些段落 > 15s 需要拆。
- 高难一致性/动作风险标注。

> 注意：VISUAL ACTION 优先于心理描写；台词要短、信息密度高；
> 每场都要能转成可执行的 AI 画面，而不是文学段落。
