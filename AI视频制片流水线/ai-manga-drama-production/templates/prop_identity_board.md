# Template — PROP IDENTITY BOARD

> 用途：把一个关键道具锁定成可复用资产（形态 / 比例 / 材质 / 使用与损坏状态 / 功能）。
> 由 `references/AI视频工作流.md` §1 角色板 + §2 场景板逻辑**抽象**而来（文档无独立道具板）。
> **不要写死具体道具**；`<...>` 为占位。背景纯白/米白，no logo / no watermark。
> 输出主体为**英文**，保持 production prompt 风格，不得简化成关键词。

---

Create an artistic 16:9 PROP IDENTITY BOARD.

[SUBJECT]: <prop name>. <one-line: what it is, who uses it, its role in the story>. <use the reference image OR describe from script>. No logo, no watermark.

VISUAL MEDIUM:
<rendering medium consistent with the project, e.g. stylized 3D cel-shaded, three-render-two look>.
Pure white / soft off-white background.
Clean production artbook presentation. No environment, no character.

REFERENCE PRIORITY:
<If reference exists:> Use @<reference> as the prop identity reference; this board controls form, scale, material, usage state and damage state.
<If none:> Reference priority: none — this board establishes the master identity for this prop.
The prop reference controls shape / scale / material / usage state / damage state; it does not override character identity or environment geography.

DESIGN DIRECTION:
Do not create a flat catalog spec sheet.
Create a cinematic prop identity board that feels like a high-end animation studio prop study mixed with an artbook layout.
Asymmetrical, elegant, memorable; large empty space, varied scale, intentional imbalance.
Avoid grids, blueprint design and repetitive turnaround presentation.

IMPORTANT LAYOUT RULE:
Do not overlap any prop images.
Every view must have clear separation and breathing room.
Keep all angles, scale studies, material details and state studies visually distinct.
No cropped key forms, no merged views, no confusing repeated layouts.

MAIN COMPOSITION:
Place one large hero view of <the prop> slightly off-center as the visual anchor.
Around it, arrange smaller supporting studies with clean spacing: <multiple angles (front/side/back/three-quarter), in-use view, scale-comparison view next to a neutral reference, key mechanism detail, surface/material close-up, damage/wear-state view>.
Each view should feel like a separate clean prop study, not a frame from one scene.

PROP IDENTITY:
<What this prop is and is NOT. Its function, who owns/uses it, what it means in the story.>

FORM LOCK:
Preserve strict form consistency across all views: same silhouette, same proportions, same key shapes, same defining contours, same signature parts.

SCALE AND USE LOCK:
<Define real-world scale via comparison (in-hand / relative to a body / relative to environment). Define how it is held / worn / operated / carried.>

MATERIAL AND DAMAGE STATE:
<List materials, one per line. Then define the canonical state(s): pristine / worn / damaged / activated, and which state is default for this project.>

FUNCTIONAL DETAILS:
<Moving/articulated parts, open/closed states, glow/energy, activation mechanism, readable functional cues.>

USEFUL REFERENCE DETAILS:
Make the prop readable for future image and video generation: clear silhouette, clear scale, clear material, clear usage state, clear damage state, clear interaction points.
The board should help an AI model keep this prop consistent across shots and understand how characters interact with it.

TEXT DESIGN:
Add one stylish PROP ID block.
Keep it minimal, bold and art-directed.
Use only:
NAME: <NAME>
ROLE: <ROLE>
CORE MOOD: <CORE MOOD>
VISUAL SIGNATURE: <VISUAL SIGNATURE>

Use small handwritten-style labels only where helpful.
Subtle editorial arrows and annotation marks are allowed, but keep them minimal and elegant.

STYLE:
minimal, cinematic, premium, artbook-like, clean, expressive, useful for production.

The final image should feel like an artistic prop identity board designed to help an AI model understand the prop's form, scale, material, usage state, damage state and how it is handled in future video staging.
