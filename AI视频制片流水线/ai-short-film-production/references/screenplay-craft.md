# 剧本工艺（格式 · 分解 · 风格拉片）

> 来源：StudioBinder 剧本格式方法论（2026-07 固化）+《After the Update》实战。格式是行业稳定知识，直接用本文件，不必重访网站。

## 一、标准剧本格式六要素

1. **场景标题 Slugline**：`INT./EXT. 地点 - 时间`，全大写左对齐。时间可用 DAY/NIGHT/DUSK/DAWN/CONTINUOUS/MOMENTS LATER；移动场景用 `INT./EXT.`；场景内换位置/时间用子标题（LATER, AT THE WINDOW）
2. **动作行 Action**：现在时；只写观众**看得见听得见**的；角色首次登场全大写；关键道具/音效可选择性大写；句子精简、多留白，禁密集大段；不写镜头指令（除非叙事必需）
3. **角色提示 Character Cue**：居中全大写；全剧名字统一
4. **扩展 Extension**：`(V.O.)` 画外音（他人听不到，AI 角色/电话内声音用它）；`(O.S.)` 画外但在场；`(CONT'D)` 同角色连续台词；`(PRE-LAP)` 下场对白提前进入
5. **对白 + 表演括号**：对白居中窄栏；括号注语气/微动作（(whispering)、(laughing)），**少用**——表演指导过多是常见错误
6. **转场 Transition**：右对齐大写，只在需要强调时用：CUT TO: / MATCH CUT TO: / DISSOLVE TO: / SMASH TO:；声音桥在动作行里写 `SOUND BRIDGE TO:`

其他：屏幕文字用 `CHYRON:`/`TITLE:` 或 INSERT——PHONE SCREEN；蒙太奇用 BEGIN/END MONTAGE 且每段带 slugline；一页 ≈ 一分钟（Courier 12pt 版式下）。

**常见错误**：过度大写、角色名不统一、括号与转场滥用、动作行指挥摄像机与表演、蒙太奇无结构。

## 二、中英对照规范（AI 短片交付用）

- 英文原声片：英文为主文本，每个元素后跟中文对照行（动作行成对段落，台词下加斜体中文=字幕参考译文）
- 制作标注（修订记录、AI 载体信号说明等）用引用块插入，不混入正文
- 台词一经用户确认即**锁定**；后续版本只改动作行

## 三、剧本分解 Script Breakdown（分镜前必做）

目的：把剧本翻译成生产要素。逐场标出：
- **人物**（谁出现、服装态、表演关键动作）
- **场景**（地点×时间态——决定需要哪些场景资产/时态变体）
- **道具**（出现即登记，含状态变化：亮/灭/拿起/放下）
- **画内文字/UI**（屏显原文逐字记录——后续直出生成需要）
- **声音事件**（音效重音、静默点、声音桥）
- **高风险时刻**（多人交互、复杂动作、文字渲染、光变）
分解产物直接决定资产清单与视频单元切分。

## 四、参考作品风格拉片方法（框架，不预设内容）

对用户指定的参考作品，产出三张"规则表"（都是**规则不是内容**，禁止照搬情节）：

1. **对白规则表**：分析该作品台词的 6-8 条可操作特征（口语密度/直接与含蓄/比喻习惯/重场戏收尾方式/名字与称呼的使用/沉默的写法/幽默位置/离场角色的语态），每条附原片例证 + 本片落法
2. **视觉语法表**：景别分布与特写触发条件/运镜性格与白名单/光的语法/色彩骨架/剪辑节奏 → 进项目语法书
3. **空间型表**：典型空间类型（户型/开窗/层高/家具密度/材质体系）→ 场景设计必须符合或书面说明偏离理由

## 五、找参考剧本（阶段 0 用）

- ScriptSlug 按类型入口：`https://www.scriptslug.com/scripts/genre/<genre>`（science-fiction/romance/drama/thriller…）——挑 2-3 部同类型专业剧本读结构与表达（场景数、对白密度、开场钩子写法），**不得复制**
- 也可检索参考影片的名场面/高能片段清单，向用户提供"影片+段落+为什么适合"的选项
