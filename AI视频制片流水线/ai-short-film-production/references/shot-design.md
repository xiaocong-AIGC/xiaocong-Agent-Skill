# 分镜设计（Shot 设计纪律）

> 来源：StudioBinder shot list 方法论（固化）+ 实战纪律。本 skill 中"分镜"最终落为视频单元里的 Shot（见 video-unit-rules.md），本文件是设计时的语法约束。

## 一、术语体系

- **景别**：ECU 大特写 / CU 特写 / MCU 中近景 / MS 中景 / MLS 中远景 / LS 全景 / ELS 大远景
- **机位角度**：eye 平视（默认）/ low 仰（体量感，稀缺使用）/ high 俯（脆弱感）/ dutch 斜（默认禁用）
- **运镜**：pan 摇 / tilt 俯仰 / push-in 推 / pull-back 拉 / dolly 移 / static 静止（静止是正当选择）
- Shot 标准字段：场号、镜号、景别、角度、运镜、画面描述、台词、音效、衔接方式

## 二、设计流程（从剧本到 Shot）

1. 逐场读剧本，标出故事节拍与必拍动作（摄影为叙事服务）
2. 按"底图锚定"分配：每个 Shot 先确定用哪张带人图/资产图做底，**只设计底图可见空间内的画面**
3. 写 Shot 细节：景别+具体动作/表情/视线（导演说戏语言，禁抽象词）
4. 台词挂载到具体 Shot，逐条做时长校验
5. 标高风险 Shot（S=说话+走位/多动作；A=复杂动作或长运镜；B=单人中景；C=静态空镜），S/A 必须写降级预案

## 三、硬性纪律（实战验证）

- **台词时长校验**：英文 2–2.5 词/秒、中文 3–4 字/秒 + 呼吸停顿；一个 Shot 必须装得下自己的台词
- **一镜一动作**：每个 Shot 最多一个运镜；情感越重镜头越静（重场戏默认全静，全片对话运镜 ≤1 处）
- **特写经济学**：特写由"改变关系的台词/情绪防线破裂/关键道具时刻"挣得；同景别最多连用 2 个；大远景全片 ≤3 个，只用于陈述孤独/空间关系
- **轴线**：同场对话镜头保持同侧；与无形体声音对话时，轴线基准=听者朝向+声音所在耳侧（画面在耳机侧留呼吸空间）
- **对无形体角色（AI/电话）的拍法**：拍听者——对方说话时镜头给听者的脸，反应就是戏
- **衔接设计前置**：每个 Shot 写"与下一镜怎么接"（cut / match cut 对齐物 / sound bridge 什么声音 / J-cut / L-cut / 同空间光变），剪辑期照此执行
- **钩子节奏**（短视频发行）：3 秒内立住核心悬念；每 20–30 秒一个再钩点；主转折不晚于全片 1/3；开场用特写不用大远景（手机小屏可读）
