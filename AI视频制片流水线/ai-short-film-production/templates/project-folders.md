# 项目文件夹骨架（片名确定后立即创建）

```
<片名>/
├── 01_brief/          # PROJECT_BRIEF、概念稿、剧本（中英对照）、风格拉片规则表、语法书
├── 02_assets/         # 参考剧照(refs/)、角色、场景母图与派生、带人比例图、道具、色卡
├── 03_units/          # 底图空间清单 + 视频单元表（分镜即单元）
├── 04_generated/      # 生成成片（图归 02，视频归此处；rejected/ 子目录放废片）
├── 05_audio/          # 角色声音资产(.wav)、SUNO 提示词与成曲
├── 06_edit/           # 剪辑规划、字幕、成片
└── 07_notes/          # 复盘笔记(REV)、PLATFORM_PLAYBOOK
```

规则：所有产物只进本项目文件夹；文件名带项目前缀+版本号（`<前缀>_<资产名>_v01.png`）；废弃文件移 rejected/ 不删除。
