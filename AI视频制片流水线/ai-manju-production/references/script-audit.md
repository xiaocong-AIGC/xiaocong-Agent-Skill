# 剧本审计、表演任务与招式链

## 1. 五元素审计

剧本进入制作前先过五元素链。定义（漫剧化）：

- **目标**：主角此场戏在争取什么；每场戏必须是通向本集/本卷目标的因果环节。删掉这场戏链条仍成立，就是废场。
- **障碍**：真正威胁到某个阶段或全局的强情境；说清威胁什么、什么规模。没有真实风险就是松弛。
- **战术**：威胁逼出来的选择，是基于当前认知的合理试探；每次失败必须返回信息、改变下一步。零信息的失败是空转。
- **反转**：反预期的转向——自己的行动反噬自己，或"我以为我在作用它，其实它一直在作用我"。每个闭合段落至少一个反转。
- **价值转变**：反转迫使观众重新评判角色（之前怎么看→之后怎么看）。写不出前后评判的反转是哑的。价值转变就是漫剧爽点的本体：打脸=观众对主角评判的骤变。

审计输出在对话中给出，不建文件：

```text
场次链检查：目标／障碍／战术／反转／价值转变 各一句判定
最弱一环：修复它收益最大的那个元素
修改建议：
1. 最小修改——保留用户版本，只动最弱环
2. 彻底修改——完整可行，允许偏离更多
3. 可选第三案——确有增益才给
```

同时核对每场的 文/武/文转武 标记齐全，文转武的点燃点明确。

## 2. 文戏表演任务

适用：对峙、谈判、告白、审问、隐瞒等对手戏。

规则：

- 先通读整场对白再建任务，不从单句台词出发。
- 阶梯：**场景方向**（全场人物共同维持的一个默契方向，通常不说破）→ 每人**动机**（同一方向、各自的燃料）→ 每人**目标**（他自己的那场仗）→ **障碍**（压着这条线的东西，破一次全场崩）→ **战术**（对着对手做的事）。
- 眼神即动作：检查对方双眼里的信任火花、每说完一点确认是否落地、偷看又在被发现前收回、量着对方比对自己。禁止情绪形容词做指令（"悲伤地""紧张地"），禁止面部编舞（"眉毛抬起"）。
- 沉默的听者也有任务（判断他是不是认真的／等笑点／护住气氛）。

输出块（进入视频提示词的表演内容）：

```text
表演任务——[角色]（全情投入自己的战术，工作发生在眼睛里）：
场景方向：[一句]
动机：[他为什么推这个方向]
目标：[他自己的那场仗]
障碍：[压线的东西，破一次的代价]
战术（逐句）：
—"[台词]"—[对对手做什么+眼睛在确认什么]
（防呆：目光始终有任务，自然眨眼，不空洞凝视。）
```

## 3. 武戏招式链

适用：交手、斗法、追逐、技能释放。物理武打与法术斗法用同一张表（[../templates/ACTION_DESIGN.md](../templates/ACTION_DESIGN.md)）。

攻防回合表逐回合填写：

| 字段 | 内容 |
|---|---|
| 回合 | R01、R02… |
| 攻方与招式 | 谁、招式名（有命名且喊出更好） |
| 发起与轨迹 | 从什么姿态发力、武器或法术走什么轨迹 |
| 接触点 | 命中／格挡／落空，碰到哪里 |
| 守方反应 | 身体如何受力、位移方向 |
| 空间变化 | 双方位置、与地标的距离变化 |
| 特效引用 | 引用特效板：刀光/技能/残影出现的时机与颜色 |
| 回合结果 | 优劣势变化，作为下一回合起点 |

规则：

- 每回合结束姿态=下一回合起始姿态；跨单元时由尾帧或视频参考继承。
- 空间用地标锚定（"逼到断墙前一步""退到祭坛台阶下"），不用"附近、周围"。
- 打斗也是戏：优劣势至少翻转一次（压制→反击就是武戏内部的反转与价值转变）。
- 超现实招式合法，但每招写清：起点、轨迹、终点、落地结果（弹坑、碎石、烟尘）。
- 文转武接点：写明由哪句台词或动作点燃（拍案、拔剑、法器亮起），镜头语言从表演任务切换到招式链。

## 4. 参考视频反推

用户提供动作参考视频时：

1. 分段：按动作单元切分，记录每段时长、动作节拍、机位与剪辑点。
2. 映射：每段动作映射到本剧角色、场景与招式链回合，登记进 ACTION_DESIGN 的参考视频映射表。
3. 改编锁定：参考视频只控制动作逻辑、身体节奏、镜头节奏；角色身份、服装、场景、画风由本项目资产控制。写明禁止带入项（原视频的人物长相、服装、背景）。
4. 生成时参考素材=视频段+本项目图片资产；提示词写法见 [video-unit-4part.md](video-unit-4part.md) 与 [cinedance-format.md](cinedance-format.md)。
