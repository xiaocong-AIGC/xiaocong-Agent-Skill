# 视频单元：格式1（中文四部分）

即梦 Seedance 提交单元。每单元=一次独立生成任务；单元划分按分镜表的自然剪辑点聚合，总时长在即梦单次生成能力内。写格式1前先按 [cinedance-format.md](cinedance-format.md) 的 4-D 流程做拆解与诊断（双格式共用）。

## 1. 制作信息（不复制给模型）

单元ID、全局Shot映射、文/武轨、建议文件名、前接/后接（来自分镜表衔接设计列）、参考资产清单、机械状态表、双格式版本号。模板见 [../templates/VIDEO_UNITS.md](../templates/VIDEO_UNITS.md)。

## 2. 固定输出结构

```text
生成时长：N秒

主体：[只列本单元出现的人物四视图与道具/特效板；外观以参考图为准]

场景：[当前机位对应的已验收单张：主视觉或新机位；多人戏附站位图连接块]

音乐：不要生成任何背景音乐，只生成画面中对应的环境音、动作音和声音效果。

Shot 01｜[景别/机位]。[起幅：镜头从哪看、谁在画面里、什么姿态、看哪里]。
[动作或量化时间轴]。[落幅：结束构图+衔接钩子]。

Shot 02｜参考图：[仅当本Shot换用另一张场景参考时写]。[本Shot内容。]
```

复制范围从"生成时长"开始；每个独立单元从 Shot 01 重新编号。

## 3. Shot 正文写法

- **起幅**：一句话钉死开场构图与人物状态（谁、在哪、什么姿态、看哪里）。
- **时间轴**：本 Shot 有多个动作节拍或有台词时用量化秒段（0–2s / 2–5s…），每段=动作+镜头状态+逐字台词（谁说、语气）。台词进行中不切镜、不换运镜。
- 一镜一运镜，按分镜表执行；运镜写成起幅构图→落幅构图。
- **落幅+衔接钩子**：执行分镜表衔接设计（出画方向、视线落点、声音尾巴、结束姿态），让下一单元能接。
- **锁定声明替代重复描述**：`人物与服装以主体参考图为准，场景以场景参考图为准，均保持不变；本镜唯一变化是[X]。`不再重述外观。
- 文戏：把表演任务的战术逐句写成可见动作（视线确认、停顿、压话、收笑）。
- 武戏：按招式链回合写动作链（发起→轨迹→接触点→反应→位移→结果）；特效按特效板颜色写可见结果；冲击帧、残影、镜头震动作为画面结果写出。
- 复杂动作按动作链顺序：起始位置→发力部位→接触点→物体移动→对方反应→结束姿态。

## 4. 禁抽象词表

下列词不进提示词，一律改写为可见可听结果：

| 抽象写法 | 改写方向 |
|---|---|
| 情绪逐渐升级 | 音量提高、身体前压、最后三个字咬得更重 |
| 气氛紧张/形成压迫感 | 谁不退、谁站着、桌上只剩餐具碰响 |
| 电影感/氛围感/高级 | 具体机位、光落在哪、什么色温 |
| 震撼/炸裂/唯美 | 具体规模、具体动作结果、具体光效 |
| 冷漠地/慌乱地 | 眼睛、嘴角、手的具体动作 |
| 快速激烈地打斗 | 招式链的具体回合 |

## 5. 台词、UI 与声音

- 台词逐字取自已确认剧本；一轮台词跨 Shot 只起句一次，后镜写"延续上句，不重新起句"。
- 抢话写清压住对方哪个字；攻击名/招式喊话写清在动作哪个阶段喊出、短而响。
- 屏幕或文字道具只有正对镜头且观众需要读清时才逐字写；否则写"保持参考图中的同一状态"。
- 音乐栏固定句不变；背景音乐在成片阶段单独制作。

## 6. 机械状态与跨单元继承

道具或人物被带着移动时（坐骑、悬浮法器、转盘、车辆），制作信息里锁定：依附物、起始位置、移动方式、朝向、接触关系、相对运动、结束位置。连续机械运动尽量同单元完成；必须跨单元时，下一单元用前一单元尾帧或视频参考，从动作下一阶段写起，逐项继承结束状态。
