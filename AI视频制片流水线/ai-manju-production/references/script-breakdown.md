# 分镜拆解

剧本与表演/动作设计确认后，把每场戏拆成分镜表。使用 [../templates/STORYBOARD_TABLE.md](../templates/STORYBOARD_TABLE.md)。

## 1. 拆解流程

1. 按地点、情绪节拍或动作单元把本集分成若干场（序列）。
2. 逐场拆镜。每个切点要有动机：新信息、反应、强调、节奏之一；说不出动机的切镜删掉。
3. 每镜填全列：景别、角度、焦段感、运镜（一镜一动，静止合法）、轴线侧、画面与动作、台词逐字+音效、衔接设计、情绪节拍、文/武标记。选镜依据见 [camera-language.md](camera-language.md)。
4. 表演任务与招式链映射进"画面与动作"列：文戏写谁看谁、听者反应；武戏引用回合编号（R01、R02…）。
5. 做景别曲线检查与同场轴线检查。
6. 从分镜表派生资产清单：需要哪些场景机位、道具、特效板、站位图、关键帧，登记到 ASSET_MANIFEST 的"待制作清单"。

## 2. 台词时长：灵活估算

- 禁止统一字数公式。按人物关系、情绪强度、节奏类型分别判断：争吵抢话密而快，威胁与摊牌慢而重，日常对话中速，静默也占时长。
- 方法：按表演节奏朗读估时，加上动作与反应的时间；单镜装不下就拆镜或让台词跨镜（跨镜台词只起句一次）。
- 以试生成结果校正估算，偏差记入 PROJECT_MEMORY 生成经验。

## 3. 衔接设计（前置）

每个镜与镜、场与场的连接点在"衔接设计"列写明，视频提示词只执行不再改设计：

- 硬切：问句切反应、动作结束切新方向。
- J-cut：下一场声音先进。L-cut：上一句尾音压在反应镜头上。
- 声音桥：同一环境声或音效盖住生成接缝。
- 匹配剪辑：写明对齐物（形状、动作、位置）。
- 尾帧/视频参考接续：连续动作跨单元时使用；下一单元从动作下一阶段写起，不重复起身、转身、拔剑。
- 场与场边界必须有设计的转场，不默认淡入淡出。

## 4. 文/武标记

每镜继承剧本的场景类型标记：文（表演任务轨）、武（招式链轨）、文转武（标明点燃点所在镜）。此列决定视频提示词阶段读取哪套写法。
