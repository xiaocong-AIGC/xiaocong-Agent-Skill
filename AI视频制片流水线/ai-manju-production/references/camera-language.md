# 视听语言：选镜与运镜

分镜表"景别/角度/焦段感/运镜"四列的填写依据。先读剧本的情绪节拍，再选镜头；镜头服务剧情，不追求花哨。

## 1. 运镜动机总则

- 每个运镜先回答："此刻要传递什么情绪或信息？"答不出来就用静止镜头。静止是合法且常用的选择。
- 每个运动写起幅构图和落幅构图两个锚点；镜头在情绪落点到位的那一刻停住。
- 无动机的运动是噪音；一场戏的运镜密度跟随情绪曲线，不均匀分配。

## 2. 运镜→戏剧功能对照

| 运镜 | 功能 | 典型时机 |
|---|---|---|
| 推镜 | 逼近内心：意识到什么、下决心、压力上升 | 反转揭晓前后、听到关键信息 |
| 拉镜 | 孤立、揭示环境、抽离 | 人物被留在原地、显示真实处境 |
| 横移/跟拍 | 伴随移动、展示空间 | 行进、巡视、入场 |
| 弧形环绕 | 对峙张力、英雄时刻 | 决斗开始前、觉醒亮相 |
| 甩镜 | 能量、两个主体的激烈连接 | 打斗中视点转移，可替代硬切 |
| 升降 | 规模、权力关系 | 大场面开场、俯瞰战场 |
| 手持感 | 混乱、主观、紧迫 | 溃逃、遇袭瞬间；少用且有目的 |
| 俯瞰 | 渺小、被审视、棋局感 | 主角被围、阵法全貌 |
| 滑动变焦 | 认知颠覆、眩晕 | 世界观被冲击的一瞬 |

## 3. 景别与角度语义

- 远/大全：地理与规模，交战双方位置关系。全景：身体动作完整可见，武戏主力景别。中景：对话与肢体并重。近景：情绪与台词重点。特写：证据、道具、眼神——稀缺资源，滥用会贬值。
- 仰拍=力量与压迫（强者亮相、boss登场）；俯拍=劣势与渺小；斜角=失衡与异常（中毒、幻境、局势失控）。
- 景别曲线：无意图时避免3个以上连续同景别；情绪升级配合景别收紧。

## 4. 文戏镜头策略

- 正反打+过肩（OTS）是对话骨架；同场对话轴线一致，越轴需有动机并在分镜表标注。
- 反应镜头经济学：谁的反应承载价值转变，就把近景给谁——说话的人不一定是重点。
- 推镜时机：留给本场最重要的一次认知变化，一场戏通常只推一次。
- 特写稀缺性：本场只给最关键的证据或眼神；台词密集段用中近景保持身体语言可见。
- 视线引导：人物看向哪里，下一镜就接什么，观众的眼睛跟着视线走。

## 5. 武戏（ACT）视听语法

1. 打击节奏：蓄力（长）→出招（极短）→收势（长）。张弛出爽感，不是均匀快。
2. 冲击帧：重击命中的一瞬插入高对比风格化画面（黑白反转、剪影），在提示词中作为可见结果写出。
3. 速度表现：拖影、残影、速度线比单纯位移更有能量；写"刀光拖出弧形残影"而不是"很快地砍"。
4. 中心构图：高速动作压在画面中心，观众眼睛不用跑。
5. 镜头震动：每次命中，镜头朝打击方向顿一下；震动幅度跟随打击重量。
6. 光色信号：每次出招有预告光（刀身一闪→光刃成形→火花迸溅）。特效签名跟随技能/功法而非角色：同一角色的不同技能可以是不同颜色与形态，每个技能保持自己固定的签名（颜色、形态、可选书法字标识）。同屏原则：当前交手双方的活跃特效必须可区分，谁在出招一目了然；相似色技能不安排同屏对打，或在形态上拉开。
7. 剪辑节奏：快切与关键帧停顿交替；重要命中后停半拍让观众"收到"；在运动最高速处切镜保持动能。
8. 空间地理：再乱的混战，观众始终知道主角在哪、威胁在哪、出口在哪。

## 6. 进入分镜表与提示词

- 焦段感列写可观察结果：压缩感（背景贴上来、浅景深隔离主体）或广角空间感（前景放大、环境铺到画框边）；CINEDANCE 版转成 FOV 语言（见 [cinedance-format.md](cinedance-format.md)）。
- 运镜列只写一个动作；动机可加括号备注。Shot 正文写成起幅构图→落幅构图。
