# 分阶段 Review 与生成验收

## 1. 剧本审计阶段

- 五元素链每场都过了？最弱环指认了？修改建议给了最小/彻底两档？
- 文/武/文转武标记齐全？文转武点燃点明确？

## 2. 表演与动作设计

- 表演任务从整场对白建立，不是单句？眼神写成有目的的动作而非情绪词？
- 招式链每回合有接触点与结果？结束姿态成为下回合起点？优劣势有翻转？
- 参考视频反推有改编锁定（保留动作逻辑、禁带原视频外观）？

## 3. 分镜表

- 每个切点说得出动机？一镜一运镜？轴线一致或越轴有标注？
- 衔接设计列每个连接点都有明确方法？场与场边界有设计的转场？
- 台词时长按节奏估算而非公式？装不下的已拆镜或跨镜？
- 景别曲线无无意图的3+连续同景别？资产清单已派生登记？

## 4. 图片资产

- 每条提示词五段骨架齐全、STYLE段逐字一致、带反文字句、100–300词？
- 四视图：固定段逐字未改？版式验收通过（四格、三全身一致、双脚完整）？
- 场景主视觉：锚点完备、拓扑唯一、大空间有尺度数字？新机位：保留清单完整、只改机位、逐张验收？
- 特效板：三态齐全、敌我色彩编码不同？
- 站位图：无填充无文字，连接块正向措辞，附图顺序最后？
- 全部登记真实路径与状态？废弃资产已从文件系统和映射移除？

## 5. 视频提示词（双格式）

- 格式1：生成时长置顶？四部分齐全？Shot 01起算？起幅/时间轴/落幅+衔接钩子？锁定声明替代重复描述？禁抽象词清零？台词逐字？音乐固定句原文？
- 格式2：架构顺序正确？首帧锁与空间视线锁？OPTICS按内容选且写成可见结果？上下文隔离（无集数、无前情、无旧tag）？全英文？
- 两版内容一致（同动作、同台词、同衔接），只是表达体系不同？
- 场景参考是当前机位对应的已验收单张，没有把多张无关方向同时喂给模型？

## 6. 生成结果验收与失败归因

按分镜表逐镜核对：身份、空间、动作、台词、特效颜色、衔接。失败先归因再行动：

| 归因 | 处理 |
|---|---|
| 资产问题（人物漂移、场景不符） | 回资产阶段修图或补机位 |
| 描述问题（动作歧义、抽象词漏网） | 只改提示词对应段，不全文重写 |
| 动作过复杂 | 按招式链减回合，或拆单元 |
| 单元过长 | 在自然剪辑点拆分 |
| 平台能力边界 | 换驱动方式（加尾帧/视频参考）或改设计 |

不设固定重试次数；同类失败重复出现时改方法，不堆重抽。

## 7. 双格式 A/B 与经验回写

- 每单元记录两版生成结果对比：身份稳定性、动作执行度、镜头服从度、光线质量。
- 胜负与原因写入 PROJECT_MEMORY 生成经验表；连续多单元一边倒时，与用户确认是否为本项目收敛成单格式。
- 只有重复验证的经验才回写进本技能文件。

## 8. 项目记忆

- 当前权威文件唯一？资产登记的是真实路径？
- 连续性（人物位置、道具机械状态、特效色彩、跨集继承）已更新？
- 下一步具体到文件和动作？恢复点一行可续？
