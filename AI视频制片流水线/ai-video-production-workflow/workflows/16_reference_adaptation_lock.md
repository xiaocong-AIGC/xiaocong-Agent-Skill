# Reference Adaptation Lock

Use after `15_reference_video_reverse_engineering.md` when the user wants to keep the source video structure but replace characters, world, style, props, or scene design.

## Process

1. Create a three-column lock: preserve from source, replace with project assets, forbidden changes.
2. Separate reference control clearly:
   - Source video controls camera, composition, timing, action relationship, and edit rhythm.
   - Character images control identity, face, body, costume, silhouette, and role.
   - Scene images control geography, lighting, material, and spatial anchors.
   - Prop images control object form and usage state.
   - Style references control rendering language only.
3. Record user-locked constraints verbatim when they affect production: character count, exact role list, ratio, no-extra-character rules, no-story-expansion rules.
4. Mark unresolved creative choices as questions instead of deciding for the user when the user has asked to approve decisions.
5. Save under `05_storyboard/` as `Pxxx_ADAPTATION_LOCK_vNN.md`.

## Quality Gate

- The file must make clear what is 1:1 from the source and what is adapted.
- The file must include negative constraints that prevent common drift, such as extra enemies, extra dancers, character swaps, scene swaps, and style overrides.
- Do not write image or video prompts until the adaptation lock exists for a reference-led imitation project.
