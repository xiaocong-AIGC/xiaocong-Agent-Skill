Camera language must come from the project CINEMATOGRAPHY_BIBLE. Dialogue duration rule: Chinese ≈ 3–4 chars/sec; a shot must hold its own dialogue. Pass criteria are written here, before generation, and checked at continuity review.

Column rules:
- Size: ECU/CU/MCU/MS/MLS/LS/ELS. Angle: eye/high/low/dutch. Move: one move max per shot; static is a valid choice.
- Axis: which side of the action line the camera sits (L/R); all shots in one scene conversation must agree or mark an authorized axis jump.
- Dialogue / Sound: verbatim line + speaker + tone, plus key SFX; verify char count fits Duration.
- Transition Out: cut / match cut(对齐物) / sound bridge(什么声音) / J-cut / L-cut / same-space anchor.
- Risk: S=多人交互或说话+走位, A=复杂动作或长运镜, B=单人中景动作, C=静态空镜. S/A shots require a degrade plan in Notes.
- Pass Criteria: one sentence — what must be readable for this shot to pass (e.g. 能看清她注意到了照片).
- Layout Ref: 3D layout render / camera name for this shot (e.g. CAM_SH010).
