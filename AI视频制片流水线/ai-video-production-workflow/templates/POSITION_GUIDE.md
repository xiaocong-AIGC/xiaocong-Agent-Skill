# POSITION_GUIDE（3D Layout 优先）

Placement control is 3D-first: render layout guides from the scene's Blender blockout. The legacy 2D colored-box overlay is a fallback for quick one-off shots only.

## 3D Layout 规则（内部）
- 同一场景所有镜头的相机必须放在同一个 .blend 里——轴线和几何一致性由此物理保证。
- 首尾帧镜头：同一台相机渲两个时刻（人偶挪位），保证首尾帧同机位。
- 人偶摆出大致姿势（站/坐/回头/低头看手机），不要 T-pose。
- 场景内放一盏方向正确的灯，白模渲染自带影子方向。
- 色块ID版：角色/关键道具各用全项目固定的专属色（中低饱和、色相差异大），场景保持中性灰。

## 复制给模型的参考素材使用写法
布局图（白模/色块渲染）用于控制：机位与透视、焦段感、人物和道具的位置大小、前后遮挡关系、屏幕方向、光影方向。
图中色块仅为位置与体积标记：砖红人形=X的位置，靛蓝人形=Y的位置。色块的颜色不控制最终画面颜色，色块本身不得出现在最终画面中。

## 不控制内容
- 不控制角色身份、服装。
- 不控制材质、质感、最终颜色和画风。
- 不控制表情和动作细节，除非另行写明。

## 2D 框图兜底模式
仅当不值得开 Blender 的单次快拍使用：在锁定场景图上画彩色线框（红绿蓝黄），每框对应一个主体，框的大小贴合透视远小近大；框内不要文字；提示词写明彩框仅为标记不得入画。
