# 多单元生产指南（>15 秒）

单条 H3 上限 15 秒。长片按视频单元拆分生产，本文件是制片层规则；每个单元的故事板与视频提示词仍**严格**使用 `h3-storyboard-template.md` 与 `h3-video-template.md` 的结构，一段不减。

## 时长架构：叙事 + 2，上限 15

- **单元生成时长 = 叙事所需秒数 + ~2 秒余量段（handle），15 秒是上限不是目标**——先按内容写节拍、加总出叙事秒数，再定生成时长（10.0s 叙事 → 生成 12s）
- **禁止把内容拉长填满单元**：填充拍（被撑长的定场、发呆、过渡）是全片"显慢"的头号来源
- 单元切分按叙事的自然段落，不按固定秒数机械均分
- 余量段只写余势：上一拍动作的 follow-through、镜头缓移、环境持续（蒸汽继续升、光斑缓移、雨继续落）——**不起新动作、不硬定格、不放台词**
- 余量段三个作用：给剪辑自由选切点；提供转场素材（叠化、音桥）；避开 AI 生成末端常见的质量衰减区
- 阶段 0 节拍表按单元分组，余量段单独占一拍并标注 `[余量拍]`；余量拍同样画进故事板末格。**选单元面板数 N（∈ {6, 9, 12, 16}）时把余量拍算进去**——叙事拍 + 余量拍 = N

## 单元边界即剪辑点

单元边界在**阶段 0 写节拍表时**就设计好，按优先级选落点：

1. **遮挡瞬间**（最稳）：whip pan、前景物/人物扫过镜头、蒸汽/烟/光斑/水花糊镜、开关门瞬间全黑——接缝天然隐形
2. **动作最高速点**（cut on action）：让一个动作跨越边界——单元 N 结束在动作行进中段，单元 N+1 首拍承接同一动作的后半；观众的眼睛跟着运动走，看不见剪辑
3. **呼吸点**：一个段落收势之后、下一段落起手之前的静止间隙

**绝不**把边界放在动作刚好完成的那一帧——那里既没有运动掩护、也没有喘息余地，是最露怯的切点。

**台词不跨单元边界**：一句话必须在单元内说完，边界落在语句间隙。跨界的音桥（J cut / L cut）用余量段的环境声做，不用台词做——台词接缝人耳最敏感。

**边界的另一半在下一单元**：单元 N+1 的首拍必须从边界帧的状态连续长出来（承接跨界动作的后半程、借遮挡完成的机位变化），不许凭空另起机位；首拍的 Panel 行以 `Opening from the boundary state — ...` 起头。

## 一致性锁（跨单元）

| 锁 | 做法 |
|---|---|
| 文案锁 | 所有单元 H3 提示词的读图规则句、角色引用句、表演引导句式、音频行**逐字复用**；故事板模板的画风段、情绪基调段逐字复用 |
| 角色锁 | 同一套 `@[char ref]` 贯穿所有单元，角色—参考图映射全片不变 |
| 场景锁 | 同场景共用同一张场景图资产；单元内不换时刻、不换天气 |
| 边界双锚（串行） | 多单元一律**串行生产**：单元 N 视频先出 → 在切点（叙事结束点）截尾帧 → ①尾帧作最后一张参考图进单元 N+1 **故事板**，映射行写：`The uploaded boundary frame is the staging origin for Panel 01 only: match its scene state, positions and camera as the panel's starting condition; take staging only, not its rendered style.` → ②同一尾帧作 `@[first frame ref]` 进单元 N+1 **H3 提示词**，在读图规则后追加：`Use @[first frame ref] as the exact first frame; continue the same scene, lighting, palette and characters. The storyboard's first panel was staged from this same frame — render the opening as one continuous emergence from it, no cut, no jump.` 单元 N 重抽 → 尾帧变化 → 下游板与视频级联重做 |
| 镜头家族锁 | 景别与机位词汇全片统一（Panel 行从同一套里选），避免某单元突然换摄影语言 |
| 后期兜底 | 提示词只能压低色偏概率，最终色调一致靠剪辑时一条 LUT 统一调色 |

## 声音分工

- 每单元音频行固定：`No background music, no score; dialogue and diegetic sound effects only.`
- 台词与音效逐单元保留：它们贴画面；剪辑时拿余量段的环境声做 J cut / L cut——声音先过界、画面后过界，耳朵一连上，眼睛就不挑剔了
- 全片只出**一条** Suno 纯音乐铺底：BPM 按小节对齐节拍网格（见 h3-video-template.md），重锤/转折对齐单元边界与收束拍——音乐连续性是掩盖视觉接缝最强的胶水

## 故事板与编号

- P## 跨单元**连续编号**（单元 1 = P01–P09，单元 2 = P10–P18……），节拍链全片唯一；各单元故事板内的 Panel 小序号从 01 重新起算即可，映射关系记在节拍表里
- **每单元一板、串行出板**（边界双锚决定了不能一张总板打包）：单元 N+1 的板必须等单元 N 的尾帧就位
- 每单元一条 H3 提示词，存档为 `40_h3_u1.txt`、`40_h3_u2.txt`……

## 单元间验收清单

1. 剪辑点两侧：色调、颗粒、光源方向无跳变
2. 角色服装与配件细节逐项对——最易漂移的是小配件、鞋、手部
3. 场景物件位置与屏幕方向逻辑连续，无镜像翻转
4. 跨界动作速度感一致，无"重新起手"感；台词完整无截断
5. 余量段可用性：至少 1.5 秒无新动作的干净余势，够剪辑挑帧
