# 场景图资产指南

本流水线不做环境识别板。场景以"场景图资产"存在：按脚本需要出图，直接作为故事板的场景参考。

## 从脚本推导清单

1. 从阶段 0 场景清单列出全部**地点 × 时刻**组合——每个组合一个场景资产（同一咖啡馆的黄昏和深夜是两个资产）
2. 每个场景至少一张**主机位图**：能看到布局全貌的角度，无人物
3. 扫一遍节拍表：若某场景有与主机位差异巨大的机位（俯视全景、仰视、贴地、某个特写角落），为该机位补一张——故事板画不出参考图里看不见的角度
4. 多单元片：在清单里按单元标注每单元用到哪些场景图；**同场景跨单元共用同一张图**，不重复生成

清单格式（写入 `25_scene_assets.txt`）：

```
S1 咖啡馆吧台·深夜 | 主机位 | 用于 U1 P01–P06, U2 P09
S1a 咖啡馆吧台·深夜 | 俯视杯口机位 | 用于 U1 P05
S2 后巷·深夜 | 主机位 | 用于 U2 P10–P12
```

## 生成方式：GPT Image 2 完整描述直出（不用 MJ，不挂风格参考）

确定画面要的是**指令服从**，这是 GPT Image 2 的强项；MJ 只属于阶段 1 的风格发散。每条提示词是三层完整描述：

```
Create a 16:9 cinematic {机位描述}: {构图层——场景内容、关键物件、尺度数字、入口或交互锚点的画内位置}. {光色层——该场景自己的光线与色调}. {统一风格段——阶段 1 锁定的媒介措辞块，逐字复用}. No people, no text, no watermark.
```

1. **构图层**按清单写全；大空间带尺度数字（宽度/纵深/关键结构高度），没有数字的场地模型默认画窄；入口/交互锚点点名画内位置（它是视频首帧的调度锚，别顶到画面边缘）
2. **光色层**按内容自由写——不同场景的色调差异是内容，不是不一致；同一天气/时刻的场景由故事本身统一光线措辞
3. **统一风格段**只写媒介（写实等级/镜头感/体积氛围/调色哲学/材质细节），不写具体颜色；全片逐字复用，是唯一的统一感来源
4. **不挂风格参考图**——风格参考会把锚图的色调强加给色调本不同的场景。参考图只在两种情况出现：**身份复现**（同一场景出第二机位/另一时刻 → 挂该场景第一张图并声明 same location, new angle only）与**关键帧**（视频阶段的首帧）
5. 补充机位图要点名与主机位的关系（如 top-down view of the same counter）

## 下游用法

- **故事板**：场景图固定排在角色板之后上传，提示词声明只取 layout、key objects 和 lighting，不重述场景外观（条款见 h3-storyboard-template.md）
- **H3 视频**：**默认不挂**——场景由故事板承载，这是 H3 的实证用法；只有环境材质/光线在成片里漂移且回修故事板无效时，才加 `@[scene ref]`（条款见 h3-video-template.md）
- 单元内时刻与天气锁定不换；换时刻 = 换场景资产 = 通常也该换单元
