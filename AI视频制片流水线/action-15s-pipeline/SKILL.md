# 15 秒高燃动作短片提示词流水线

把用户的一个想法，经五个带确认门的阶段，变成一套可直接投入 Midjourney、GPT Image 2、Seedance 2.0、Suno 的提示词资产链。题材锁定：高燃动作 / 对决类。

## 流程总览

| 阶段 | 产出 | 推进条件 |
|---|---|---|
| 0 故事定稿 | 15 秒完整故事 + 节拍表（中文） | 用户确认剧本 |
| 1 角色形象探索 | Midjourney 全身提示词，每个主要角色一条 | 用户确认全部角色的 MJ 图 |
| 2 角色设定板 | GPT Image 2 提示词，每角色一条 | 用户做完设定板 |
| 3 分镜故事板 | GPT Image 2 制片板提示词一条 | 用户做完故事板 |
| 4 视频 + 音乐 | Seedance 2.0 提示词 + Suno 纯音乐风格提示词 | 交付，按需微调 |

**一次只推进一个阶段。** 每阶段输出后明确停下，告诉用户"确认后进入下一步"。不要因为内容都能推导出来就一口气全给——用户要拿每阶段产物去外部工具实际生成图/板，下一阶段的提示词依赖那些真实产物。

**判断当前阶段。** 用户可能中途进入（"设定板做好了"、"直接给我 Seedance 提示词"）。根据用户的话和已有存档判断处于哪个阶段，从那里继续；缺上游信息就先要（如：还没有确认的剧本，就先回到阶段 0）。

## 全局规则

1. **内容全推导，模板只借格式。** references/ 里的模板给出的是段落结构和描述方式；片名、文案、角色、节拍、风格词全部从本次确认的故事推导。绝不把模板示例里的具体内容（片名、招式、光效颜色等）带进产出。
2. **BEATS 是贯穿链。** 阶段 0 节拍表的 P## 编号，就是阶段 3 故事板的面板编号，也是阶段 4 Seedance 的 BEATS 编号。三处数量一致、内容逐格对应。上游任何修改都要同步整条链。
3. **资产链单向引用。** 每个主要角色的 MJ 确认图 → 对应角色设定板 → 分镜故事板 → 视频。阶段 1 必须覆盖全部主要角色；阶段 2 不得缺少任何主要角色的 MJ 确认图。每阶段提示词引用上一阶段的真实产物作参考图；引用只声明用途（外观 / 布局锚点），不重复描述参考图里已锁定的内容。
4. **语言分工。** 与用户沟通、故事、节拍表用中文；给四个工具的提示词一律英文。
5. **画面写具体。** 情绪翻译成表情和动作；镜头语言用专业术语（景别、角度、运镜、轴线、屏幕方向）；每格只写一个动作瞬间，禁用 then / after / next / first / later 等时序词；特效必须依附于可见的发力源（拳、脚、接触点）。
6. **落盘存档。** 在当前工作目录建 `<项目代号>/` 文件夹，每阶段产出同时写入文件（结构见文末），方便中途接续和复盘。

## 阶段 0｜15 秒故事与剧本

输入是一句想法。输出全中文，结构：

- **片名**（中文 + 英文）
- **Logline** 一句话
- **场景钩子**：一到两句钉死场地——这个场地会原样进入故事板的 geography 锁和 Seedance 的 ENVIRONMENT
- **角色速写**：0–3 个。每个角色给名字、身份、外形关键词（发型/头饰/服装块面/体型/站姿）、战斗风格、视觉签名（如专属光效色）。纯场景片（0 角色）写清叙事主体是什么（环境、机械、天象等）
- **15 秒节拍表**：节拍数 N 从 {4, 8, 10, 12, 14, 16} 中按动作密度选——高速连击对决用 12–16，少而重的大开大合用 4–8。每拍一行：

  `P01 | 0.0–1.2s | 镜头要点 | 单一动作瞬间`

  时间区间加总 = 15 秒。每拍必须是一个可画成单格的静态可读瞬间。
- **收束**：最后一拍是可读的胜负 / 反转 / 定格瞬间

默认无台词，音乐 + 音效驱动；若故事必须有一两句台词，在对应节拍标注谁说、说什么、语气，并确保该拍时长够说完。

输出后停：请用户确认或提修改。节拍表一经确认，P## 编号即锁定。

## 阶段 1｜Midjourney 主要角色形象探索

本阶段同时锁定统一视觉方向和主要角色形象，为阶段 2 提供真实参考图。按阶段 0 的主要角色数量输出：每个主要角色一条独立提示词；2 个角色必须输出 2 条，3 个角色必须输出 3 条。0 角色的纯场景片改为一条核心场景主体提示词。

每条角色提示词固定使用简洁句式：

```
Midjourney: full body view of [main character description based on the script], illuminated by [lighting and atmosphere]. --ar 2:3 --stylize 1000 --preview
```

- 角色描述只保留身份、整体体型或轮廓、3–5 个不可丢失的外观识别点；从已确认剧本推导，不写剧情动作。
- 所有主要角色沿用同一视觉媒介、造型语言、光线体系与气氛，使各自生成的图属于同一部影片。
- 保持提示词为一个主体、一句主体描述和一句光线气氛，不堆叠场景叙事、镜头术语、微观材质、质量标签或互相矛盾的风格词。
- 固定使用 `--ar 2:3 --stylize 1000 --preview`；不要追加 `--no text`、`--sref`、`--profile` 或其他参数，除非用户明确要求。
- 非人形、无四肢或物体型角色仍使用 `full body view`，让整个角色实体完整入画。

输出后停：等用户分别生成并确认每个主要角色的 MJ 形象图。记下统一视觉方向和每个角色对应的确认图；全部确认后才进入阶段 2。阶段 2 的每个角色设定板必须引用该角色自己的 MJ 确认图。

## 阶段 2｜角色设定板（GPT Image 2）

读 `references/character-board-template.md`，按模板为**每个角色出一条独立提示词**（每角色一张板，各自以该角色选中的 MJ 图为 reference image）。需要推导填入的：角色名与身份、对 MJ 图的修正指令、VISUAL MEDIUM（与选定风格一致）、CHARACTER ID 四行（NAME / ROLE / CORE MOOD / VISUAL SIGNATURE）。

纯场景片（0 角色）：跳过本阶段，直接进阶段 3，故事板的 [REFERENCES] 改为引用选中的 MJ 场景图作环境风格参考。

输出后停：等用户做完全部设定板。

## 阶段 3｜分镜故事板（GPT Image 2）

读 `references/storyboard-template.md`。一条提示词出一张 16:9 制片板，面板数 = 阶段 0 的节拍数 N。需要推导填入的：

- [HEADER] 两行引号文案：片名 + 一句本片气质短句
- [SUBJECT] 一句本片动作概念 + 本片要优先保证的视觉要素
- [REFERENCES] 每角色一条 Image A/B/C 映射（只列剪影级特征），图片上传顺序要与 A/B/C 对应
- [CONTINUITY] 中的场地锚点、允许的攻击手段、双方距离逻辑
- [COUNT LOCK] 按实际角色数写
- [BEATS] 每拍一行 `P## / shot tag / beat name: 画面描述`，从节拍表扩写：机位与角度、姿态、接触点、特效记号及其发力源、屏幕方向、空间结果

输出后停：等用户做完故事板。

## 阶段 4｜Seedance 2.0 + Suno

读 `references/seedance-template.md`。

**Seedance 提示词**：开头三段固定引用规则（故事板仅作布局锚点、角色图仅作外观来源，按实际角色数选变体），然后 VISUAL STYLE / AUDIO / ENVIRONMENT / EMOTIONAL GUIDANCE / RHYTHM + ESCALATION / BEATS 六段。BEATS 与故事板逐格对应，在每格基础上补最终成片的信息：材质、光效色、氛围、动态细节、音画点。

**Suno 纯音乐提示词**：给 1–2 条英文风格提示词候选，只写风格不写歌词，要素：流派混搭 + 情绪 + 核心乐器/音色 + 节奏或 BPM + 能量走向（对齐 15 秒动作弧线，如 rising energy with a hard final hit）+ `instrumental, no vocals`。

交付后按需微调。用户若此时要改剧情或分镜，提醒需要回到对应上游阶段并同步 BEATS 链。
