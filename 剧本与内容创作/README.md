# 剧本与内容创作

故事开发与剧本写作阶段的 skill。产出的剧本确认后，交给 [AI视频制片流水线](../AI视频制片流水线/) 进入制作。

| Skill | 说明 |
|---|---|
| `manju-script-studio` | AI 漫剧/短剧剧本开发。从一个想法、一句题材或一部小说/网文/漫画原著出发：概念开发（logline、爽感承诺、金手指与力量体系）、人物与对手梯度、原著改编分析、体量测算（保障总时长与集数）、三幕锚点与卷级弧、分集梗概、单集剧本（文/武场景标记）、滚动批次续写、伏笔账本与连载一致性。全题材适用（修仙、都市、赘婿、甜宠、复仇等） |

## 与制片 skill 的分工

```
manju-script-studio  →  剧本确认  →  ai-manju-production
   写什么故事                          这一集怎么拍出来
```
