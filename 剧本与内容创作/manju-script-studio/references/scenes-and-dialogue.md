# 场景写作与台词

## 1. 剧本格式

- 场景标题：`第X场｜地点 · 时刻（文/武/文转武）`
- 动作行：现在时，只写观众看得见或听得见的内容。
- 对白：角色名+台词；需要时标注 V.O.（旁白）/ O.S.（画外）。
- 节拍标注：每场开头一行五元素速记（目标/障碍/战术/反转/价值转变）。

## 2. 五元素写戏

写前先答五问：这场谁要什么？什么拦着？他试什么招？哪里反预期？观众对谁的看法变了？答不全先补设计再写。

写完自审：删掉这场，链条断不断？不断就删或合并进相邻场。

## 3. 台词规则

- 潜台词优先：人物说的和想的不同层；直给信息的台词换成动作，或让对手把话逼出来。
- 能用画面就删台词。每句过一遍"删了故事还成立吗"。
- 声音区分：按人物档案的说话习惯写；写完盲测（遮住名字认人）。

### 台词人味六律（实证校准，交付前逐句过）

1. **主语回到人**：台词主语是"我/你"，说自己做过、见过、要做的事，不说格言。（"雷是我接的，我记得" 胜过 "雷没忘"——后者把主体让给了修辞。）
2. **禁对仗金句**：对仗、拟人、双关是"写"的痕迹，人在情绪里说不出对仗。句子"太漂亮"就拆掉重说。
3. **主题走经历不走宣讲**：主题词藏在"我干了什么"里带出；主题句本身只放卷首语、旁白或字幕卡，不入人物之口。（《仙逆》"顺为凡，逆则仙"是卷首语；第一章人物台词全是"书读的怎么样了""个子又长高了"。）
4. **情感宁给勿耍**：托付与恳求（"别忘了我"）比酷的切割（"你别喊我"）更痛。写完先问：这句话是给对方的，还是给观众看帅的？
5. **狠话=摆事实**：把账摆到对方面前（"这些都应是落在你身上的雷"），不做宣言（"从今天起……"式的话没人说）。
6. **生活流优先**：日常戏的台词是称谓、家常、半截话；信息靠人情场合自然带出（亲戚来访带出仙门名额），不靠人物播报设定。
- 漫剧专项：
  - 旁白/内心OS：用于金手指界面、境界说明、时间跳跃；克制使用，旁白不代替戏剧冲突。
  - 攻击名/招式喊话：升级流标配；喊话在招式发动瞬间，短而响。
  - 短句化：单句不超过一口气；长解释拆成对手戏问答。

## 4. 武戏在剧本层的写法

剧本只写回合级事实：谁出招、结果、位移、优劣势变化。招式的轨迹细节留给制作技能的招式链表；但点燃点（文转武的那句台词或动作）、翻转点（优劣势逆转）、终结招必须在剧本中明确。

## 5. 修订路径

用户拿剧本来改时：先五元素定位最弱一环 → 给两档修改（最小修改保留原版只动最弱环；彻底修改允许偏离更多）→ 改动涉及台词或事件时，同步更新分集梗概、伏笔账本与连载记忆。
