# 滚动批次与连载一致性

## 1. 批次规则

- 首批3–5集：留存生死线。集集有钩、反转密度最高、金手指与人物立住。
- 之后每批3–5集。每批开工前必读：SERIES_BIBLE、SEASON_OUTLINE（校对体量余量）、FORESHADOW_LEDGER、上一批的确认记录。
- 每批交付后更新：分集梗概与实际执行的差异、事件清单消耗、伏笔账本、人物状态表。

## 2. 伏笔账本

每把契诃夫之枪登记：伏笔内容、类型、埋设集、计划回收集、状态（未回收/已回收/已废弃）。

规则：

- 无未回收的枪走到剧终。
- 无提前开火（回收早于埋设）。
- 废弃伏笔显式登记原因，不静默丢弃。

## 3. 连载一致性

- 人物状态表（在 SERIES_BIBLE 更新）：境界/能力、伤势、关系、持有物按集登记变化。
- 世界观规则一经使用即锁定；后续需要突破时写"规则升级"事件，不静默矛盾。
- 跨批次时间线：每集标注剧内时间跨度，累计校对。

## 4. 交付前自检

- 本批每集：钩子/压制/反转/待续钩齐全？观众评判变化写得出？
- 每场：五元素速记齐全？文/武/文转武标记齐全？
- 台词：盲测通过？可删台词清零？旁白未超量？
- 账本：本批新埋与已回收的伏笔全部登记？
- 体量：剩余事件池仍 ≥ 剩余集数×1.2？不够时向用户预警并给扩池方案。
