# 概念与人物

## 1. Logline

一句话=主角+欲望+障碍+钩子。检验：只听这一句，想不想听第二句？
高概念检验：能否一句话讲给平台运营听懂并觉得能卖。

## 2. 爽感承诺

立项就确定本剧卖什么爽：逆袭、打脸、复仇、升级、扮猪吃虎、甜宠、虐恋翻盘……可组合，但主爽感唯一。爽感承诺决定钩子类型、反转密度和每卷付费卡点的形态，写入 SERIES_BIBLE。

## 3. 金手指与力量体系

- 金手指：主角的不对称优势（系统、重生记忆、至宝、血脉）。规则必须清楚：能做什么、代价是什么、什么时候失效。规则不清的金手指会毁掉后期悬念。
- 力量体系：修仙境界、异能等级、职业段位等。写清层级名称、跨层差距、晋升条件。力量体系是对手梯度的刻度尺，也是卷级弧的天花板。

## 4. 人物

- 主角：want（他要的）与 need（他真正缺的）分开写；小传一段；辨识特征三个以内。
- 对手梯度：一卷一个更强对手，登记在力量体系刻度上；最终对手开局就存在（明线或暗线）。
- 配角：每人一个功能+一个反差点；功能重复的配角合并。
- 声音区分：每人固定的说话习惯（句长、口头禅、敢不敢直说）。盲测：遮住名字能认出谁在说。

## 5. 题材钩子手册

按题材选开场钩子方向（前3秒的画面+第一句话）：

- 升级流/修仙：当众践踏→金手指觉醒预告；被轻视→实力泄露一角。
- 赘婿/扮猪吃虎：身份错位——被轻视的人一个反常细节暴露不凡。
- 复仇：结果前置——先看到复仇现场一瞬，再回到起点。
- 甜宠：高张力误会或身份反差的第一次碰撞。
- 通用：证据先行、祝贺反转、动作未完成、问题直入。

钩子只定方向；具体画面在剧本与制作阶段实现。

## 6. 产物与确认

概念文档一页：logline、题材与主爽感、金手指与力量体系、主要人物与对手梯度、对标作品2–3个。用户确认后进入 [structure-and-volume.md](structure-and-volume.md)。
