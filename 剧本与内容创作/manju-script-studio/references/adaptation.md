# 原著改编（小说/网文/漫画）

## 1. 采样分析

长原著不通读全文再动手。先采样：开头3–5章逐章读、每卷开头与结尾章、读者高赞提到的名场面章节。产出：题材与主爽感判断、力量体系摘要、主线概括、名场面清单。

## 2. 章节功能提取

按批次过章节（每批只读一段，登记完再读下一段，不整本载入）。每章记录：本章事件、出场人物、爽点类型、对主线的功能（推进/铺垫/支线/注水）。

## 3. 故事单元与可拍事件清单

把章节聚合成故事单元（一个完整因果段落=一到数集的原料）。每个单元登记：起因→过程→结果、参与人物、所需场景与资产量级、爽点强度。

可拍事件清单=全部故事单元展开的事件列表，登记进 SEASON_OUTLINE，是体量测算的输入。

## 4. 改编价值评估与取舍锁定

- 必留：主线转折、高赞名场面、人设确立戏。
- 合并：功能重复的配角与过场——配角合并是漫剧改编的主要压缩手段。
- 删除：纯文字爽（境界感悟长描写）、与主线无关的支线。
- 改写：不可视化的内心戏改成可拍的外部动作或对手戏。

取舍结果写成改编锁定表：原著内容→处理方式→对应集数段。用户确认后锁定，后续批次不反复。

## 5. 版权边界

改编他人作品需向用户提示版权边界：个人测试研究与商用授权是两回事。做原创化改编（换人名、世界观、关键设定）时，把替换表写进改编锁定，后续批次统一执行。
