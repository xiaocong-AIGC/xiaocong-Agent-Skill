# 结构与体量

## 1. 体量测算（写任何剧本之前）

- 集数 = 总时长目标 ÷ 单集正片时长。两个输入与用户确认（例：120分钟 ÷ 2分钟/集 = 60集）。
- 体量校验：可拍事件清单条数 ≥ 集数×1.2（每集消耗约1个核心事件，留20%余量）。
- 不足处理：扩支线（新对手、新场景线、人物关系线）、拆大事件为多集连续事件。扩完再测，达标才开写。
- 测算表写入 SEASON_OUTLINE；后续每批次校对余量，不足时提前预警。

## 2. 全剧三幕锚点（先钉死）

- 开局钩子事件（第1集）、中点大反转（全剧中段的世界观或关系颠覆）、结局（主线如何收）。
- 三点确定后一切分集向它们收敛；中途改锚点=重新过体量测算。

## 3. 卷级弧

- 每10–15集一卷。每卷用五元素设计卷级弧：卷目标、卷障碍、主角战术演进、卷末大反转、卷末价值转变。
- 卷末=大爽点+大钩子（付费卡点位）；对手梯度一卷一级，对应力量体系刻度。
- 文武配比检查：连续3集无武戏或连续3集无文戏时预警（除非有意设计）。

## 4. 单集节拍（起承转合）

- 起：前3秒钩子（按题材钩子手册选方向）。
- 承：压制/憋屈/蓄力——障碍压向主角。
- 转：本集反转——战术生效、金手指亮出、打脸。
- 合：价值转变落地+待续钩（新威胁或新谜团探头）。

每集登记消耗的事件清单编号。

## 5. 分集梗概

前10集写详版（每集：核心事件、反转、待续钩、消耗事件编号、文/武场次预估）；之后各卷写粗版（卷弧+关键集）。梗概确认后才进剧本写作（[scenes-and-dialogue.md](scenes-and-dialogue.md)）。
